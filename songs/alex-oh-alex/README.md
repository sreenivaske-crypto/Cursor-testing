# Alex, Oh Alex (We're Gonna Miss You)

A farewell pop-folk anthem for Alex — written from the team's own lyrics.

The original words are all still here: the AIR values (Agility, Inclusive, Responsible), *yes we tried matching you*, *we never gonna stop*, and *permanently written in our hearts*. They are shaped into a song a room can actually sing.

## What's in this folder

| File | What it is |
| --- | --- |
| [LYRICS.md](LYRICS.md) | Full lyrics, plus a 90-second party cut |
| [CHORD_CHART.md](CHORD_CHART.md) | G / D / Em / C chart for guitar or ukulele |
| [alex_oh_alex.mp3](alex_oh_alex.mp3) | Demo recording (melody on flute, band underneath) |
| [alex_oh_alex.mid](alex_oh_alex.mid) | MIDI source, if you want to rearrange it |
| [singalong.html](singalong.html) | Projectable lyric sheet for the farewell |
| [compose_song.py](compose_song.py) | Regenerates the MIDI |

## How to use it on the day

1. Open `singalong.html` on a laptop or TV, or print `LYRICS.md`.
2. Play `alex_oh_alex.mp3` and sing the flute line — that **is** the vocal melody.
3. If someone has a guitar, use the four chords in `CHORD_CHART.md` and skip the MP3.
4. Short on time? Use the party cut in `LYRICS.md`: Verse 1 → Chorus → Bridge → Final Chorus.

## Musical notes

- **Key:** G major (easy group range)
- **Tempo:** 104 BPM
- **Feel:** mid-tempo pop-folk, proud more than sad
- **Hook:** *Alex, oh Alex — we miss you*
