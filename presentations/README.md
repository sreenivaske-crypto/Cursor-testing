# NIDS Client Presentation

Client-ready PowerPoint briefing on Network Intrusion Detection System (NIDS) architecture.

## Files

- `NIDS_Client_Presentation.pptx` — 12-slide deck for customer / client meetings
- `assets/nids-architecture-diagram.png` — architecture diagram used in the deck
- `generate_nids_pptx.py` — regenerates the `.pptx` if you need to edit content

## Regenerate

```bash
python3 presentations/generate_nids_pptx.py
```

Requires `python-pptx`.
