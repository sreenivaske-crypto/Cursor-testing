# Pillar Foundation — 5-Story Building (3D)

Interactive Three.js model of a **standard isolated pillar (pad footing) foundation** for a 5-storey RCC framed building.

## What’s modelled

- 4 × 3 column grid at **5.0 m** centres
- Isolated pad footings **2.0 × 2.0 × 0.50 m**
- Pedestals and **450 × 450 mm** columns through **5 storeys**
- Plinth beams and floor beams
- Translucent floor slabs and building envelope
- Soil cutaway showing **1.8 m** founding depth

> Sizes are typical educational defaults (assumed SBC ≈ 180 kN/m²). Not a site-specific structural design.

## Run locally

```bash
cd pillar-foundation-3d
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Controls

- **Drag** — orbit
- **Scroll** — zoom
- **Right-drag** — pan
- Side panel toggles layers and exploded view
