# Arrow Snake

A simple keyboard game for Windows. Steer with the arrow keys, eat orbs, and beat your high score.

## How to play

1. Open `index.html` in any browser (Edge, Chrome, Firefox).
   - Double-click the file, or right-click → **Open with** → your browser.
2. Press **Space** (or any arrow key) to start.
3. Use **↑ ↓ ← →** to move.
4. Eat the glowing orbs to grow and score.
5. Avoid the walls and your own tail.
6. Press **Space** after a game over to play again.

Your best score is saved in the browser.

## Controls

| Key | Action |
| --- | --- |
| Arrow keys | Move |
| Space | Start / restart |
